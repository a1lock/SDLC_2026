# ИС «Склад»

Прототип для лабораторной работы № 2 по дисциплине «Автоматизация процессов жизненного цикла программных средств». Основа проекта — утверждённое техническое задание на информационную систему складского учёта материалов.

## Что делает текущий прототип

- Запускает сервер FastAPI и PostgreSQL 17 в отдельных контейнерах.
- Показывает стартовую страницу по адресу `/`.
- Проверяет доступность приложения и базы данных через `GET /health`.

Функции Ф1–Ф6 из ТЗ будут реализованы на следующих этапах проекта. Текущий код предназначен для проверки развёртывания на стендах `test`, `stage` и `prod`.

## Стек

Ubuntu Server 24.04 LTS, Docker Engine 27.5.1, Docker Compose 2.32.4, Python 3.14, FastAPI 0.115.6, Uvicorn 0.34.0, PostgreSQL 17. Python и PostgreSQL запускаются в контейнерах, поэтому установка отдельных версий Python и СУБД в гостевой ОС не требуется.

## Запуск

```bash
cp .env.example .env
# Задайте собственный POSTGRES_PASSWORD в .env.
sudo docker compose up --build -d
curl http://localhost:8000/health
```

Остановить стенд: `sudo docker compose down`. Данные PostgreSQL остаются в именованном томе `postgres_data`.

## Требования проекта

В итоговой системе должны работать подсчёт поставщиков материала, регистрация единицы хранения, список поставщиков материала и подсчёт поставщиков по адресу банка. Дополнительно ТЗ предусматривает справочники, роли пользователей, проверки ошибок, автоматические тесты и миграции БД. Для реализации нужны файлы сборки и развёртывания, документация и воспроизводимые инструкции.
